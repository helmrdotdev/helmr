# Synthetic monthly sales

These eight rows are fictional, complete monthly aggregates for two products
and two regions in August and September 2026. Each `(month, product, region)`
combination is unique. `revenue_usd` is revenue in whole US dollars, not unit
counts or cumulative revenue. There are no quoted fields or missing values.

Compare September with August. Explain which product and region account for
the difference. A revenue change alone cannot establish its cause: this dataset
contains no prices, order counts, campaign data or customer behavior.

The file is small so a reader can independently check the calculations. It is
not evidence about a real company. Replace it deliberately when adapting this
example; update the schema and completeness assumptions as well.
